Personal resume website for a Computer Science student at the University of Michigan-Flint, expecting to graduate in Fall 2027 and pursuing software engineering.

## Contents
- Introduction and professional summary
- Education and skills
- C++ group projects: UNO Card Game and Sudoku Solver

- Professional contact and two GitHub links
- Resume PDF

## Local preview
Open `index.html` in a browser. Keep `resume.pdf` beside it. Styling is included in the HTML; no build process or external scripts are needed. Navigation appears in a sidebar on desktop and above the content on narrow screens.
